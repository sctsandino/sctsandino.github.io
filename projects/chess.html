CheckMate! | Chess Game

Year Developed: 2021

Developers:

  • Ignacio, Rea E.
  • Reyes, Louis Armando
  • Sandino, Shierwin Carl T.
  • Vidal, R-Mia M.

Tech Stack: Python, Pygame, VS Code

Project Overview

CheckMate! is a 2D strategy-based chess game that faithfully replicates the official rules and mechanics of traditional chess. The game allows both single-player and local multiplayer modes, helping users sharpen their strategic thinking and decision-making skills.

Key Features

  • Full chess rule implementation
  • Single-player and local multiplayer
  • Turn-based logic and move validation
  • Clean and minimal UI
